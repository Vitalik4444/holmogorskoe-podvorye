# Ярмарка выходного дня — Холмогорское подворье

Одностраничная афиша открытия. Без фреймворков и сборщиков: HTML, CSS и один файл на JavaScript.

## Как посмотреть

**Быстро:** собрать и открыть двойным кликом.

```
python build.py
```
→ откройте `dist/index.html`

Проверено: шрифты, иконки, орнамент и скролл-видео работают и при открытии файлом.

**Как на боевом сервере:**

```
python -m http.server 8000 --directory dist
```
→ http://localhost:8000

## Что делает `build.py`

Собирает `dist/` — только те файлы, которые реально используются в разметке и стилях
(из 12,7 МБ ассетов в сборку попадает 4,3 МБ), кладёт `index.html` в корень
и выпрямляет пути. Папку `dist/` можно целиком скопировать на сервер.

## Выкладка на VPS

1. Скопировать содержимое `dist/` в корень сайта.
2. **Проверить поддержку Range-запросов** — без них скролл-видео замрёт на первом кадре:
   ```
   curl -I https://podvorye.com/assets/video/hero-rows.mp4
   ```
   В ответе должно быть `Accept-Ranges: bytes`. Nginx и Apache умеют из коробки.
3. Проверить, что `.mp4` и `.woff2` отдаются с правильными типами и кешируются.

## Структура

```
src/            исходники: index.html, styles/, scripts/
assets/         шрифты, логотипы, орнамент, иллюстрации, иконки, рендеры, видео
docs/           структура, дизайн, айдентика, аудит, вопросы заказчику
dist/           сборка (создаётся build.py, в репозиторий не нужна)
build.py        сборщик
CLAUDE.md       правила проекта: палитра, шрифты, тон, границы выпуска
```

## Что помнить

- Сервер сам подтягивает новые коммиты раз в пять минут (`podvorye-update.timer`),
  так что после `git push` делать ничего не нужно. Правки прямо в `/var/www/podvorye.com`
  затрутся — менять сайт только через репозиторий.
- Режим работы написан в трёх местах: такт «Когда приезжать» и строка в подвале —
  в `make_page.py`, третье — `LINES` в `make_og.py` (картинка для мессенджеров).
  После правки: `python make_page.py && python make_og.py && python build.py`.
- Видео сжимается с `-g 12` — без плотных ключевых кадров перемотка идёт рывками
  (195 мс против 30). Команда — в `docs/VIDEO-PROMPT.md`.
- Отступать от брендбука нельзя. Все правила и два согласованных исключения — в `CLAUDE.md`.
