## Что внутри

Статика без сборщиков: `index.html`, `privacy.html`, `terms.html`, папки `styles/`,
`scripts/`, `assets/`. Всё содержимое папки можно скопировать на любой сервер.

## Важно при переносе на свой сервер

Видео в первом экране привязано к прокрутке, а перемотка невозможна без поддержки
Range-запросов. Проверить одной командой:

    curl -I https://ваш-домен/assets/video/hero-rows.mp4

В ответе должно быть `Accept-Ranges: bytes`. Nginx и Apache умеют из коробки.
